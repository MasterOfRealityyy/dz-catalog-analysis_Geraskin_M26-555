Домашнее задание №1 по дисциплине "Программирование на Python".
Это сквозной мини-проект, объединяющий материал пройденных тем: от переменных и чисел до множеств, словарей, итераторов и генераторов. 
В нем релизован набор функций для внутреннего отчета стримингового сервиса, которые анализируют каталог фильмов — считают статистику, категоризируют записи, строят отчеты по жанрам и актерам, ищут топовые позиции.
Задание разбито на 9 этапов, которые логически продолжают друг друга и вместе образуют один файл catalog_analysis.py. Каждый этап опирается на функции, написанные на предыдущих этапах.
